# KZOCN — Контекстна законодавча оцінка суспільної небезпечності (КК України, 2001–2026)

Репозиторій містить програмний комплекс, первинні тексти 27 історичних редакцій Кримінального кодексу України (Закон № 2341-III), реляційну базу даних та інтерактивну 3D-візуалізацію індексів **контекстної законодавчої оцінки суспільної небезпечності ($I_i^{\text{КЗОСН}}$)** за методом **«In Context»** проф. М. В. Карчевського.

---

## Методологічна основа

Метод контекстної законодавчої оцінки суспільної небезпечності («In Context») обґрунтовано у праці:
> Карчевський М. В. *Кримінально-правова охорона інформаційної безпеки України : монографія* / М. В. Карчевський ; МВС України, Луганський державний університет внутрішніх справ імені Е. О. Дідоренка. – Луганськ : РВВ ЛДУВС ім. Е. О. Дідоренка, 2012. – 528 с. ([Текст монографії](https://karchevskiy.com/wp-content/uploads/2020/04/karchevskiy-m.pdf))

Індекс кожної частини статті Особливої частини КК України в межах конкретної редакції обчислюється за формулою:

$$I_i^{\text{КЗОСН}} = \frac{N_{\max} - N_i + 1}{N_{\max}} \times 100$$

де:
* $N_{\max}$ — загальна кількість унікальних конструкцій санкцій в Особливій частині відповідної редакції КК України;
* $N_i \in \{1, \dots, N_{\max}\}$ — ранг конкретної санкції за суворістю у лексикографічно впорядкованому ряду унікальних санкцій цієї редакції (від найсуворішої $N_i = 1$ до найм'якшої $N_i = N_{\max}$ з урахуванням історичної редакції ст. 12 КК України та інверсії альтернативних основних покарань).

## Структура репозиторію

```text
KZOCN/
├── data/
│   ├── raw_html/                     # 27 офіційних редакцій КК України з zakon.rada.gov.ua (2001–2026)
│   └── checksums_sha256.txt          # Контрольні суми SHA-256 первинних HTML-файлів
├── src/
│   ├── fetch_editions.py             # Завантаження історичних редакцій КК України
│   ├── sanction_parser.py            # NLP-парсер санкцій, класифікація за ст. 12 КК та лексикографічний ключ
│   ├── build_database.py             # Побудова SQLite-бази даних та зведеної книги Excel
│   └── export_web_data.py            # Генерація JSON/JS-пакета для 3D-візуалізації
├── web/
│   ├── index.html                    # Інтерактивний 3D-застосунок (Three.js)
│   └── data.js                       # Згенерований масив даних для автономної роботи у браузері
├── kzocn_kk_ukraine.db               # Реляційна база даних SQLite (22 184 норми-спостереження)
├── KZOCN_Database_2001_2026.xlsx     # Зведена книга Excel (статистика, динаміка 2001–2026, повна база)
├── In_Context-2++.xlsx               # Еталонні розрахунки для валідації (2001, 2019, 2020)
├── requirements.txt                  # Залежності Python
└── CITATION.cff                      # Метадані для наукового цитування
```

## Відтворення розрахунків

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
2. *(Опційно)* Завантажте HTML-редакції КК України (вже збережені у `data/raw_html/`):
   ```bash
   python src/fetch_editions.py
   ```
3. Побудуйте базу даних SQLite та таблицю Excel з нуля:
   ```bash
   python src/build_database.py
   ```
4. Оновіть дані для веб-візуалізації:
   ```bash
   python src/export_web_data.py
   ```

## Інтерактивна 3D-візуалізація

Відкрийте файл `web/index.html` безпосередньо у браузері або запустіть локальний сервер:
```bash
python -m http.server 8085 --directory web
```
та перейдіть за адресою `http://localhost:8085`.
